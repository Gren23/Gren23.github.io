Mech-Vision 安装指南

Mech-Vision 安装指南

文档概述

梅卡曼德视觉系统软件用户手册 v2.1.2 的安装部分。

一、系统要求

项目 要求
操作系统 Windows 10 及以上
CPU 需支持 AVX2 指令集
内存 8 GB 及以上
硬盘 128 GB SSD 及以上
GPU 可选，推荐 NVIDIA GTX 1050 Ti 或以上

CPU 具体要求：

  • 无独立显卡：Intel i5-12400 及以上
  • 带独立显卡：Intel i7-6700 及以上 + GTX 1050 Ti（推荐 i5-12400）

二、下载软件安装包

  • 下载渠道：https://downloads.mech-mind.com.cn/?tab=tab-suite
  • 安装包集成内容：
    • Sentinel LDK 加密驱动（软件授权）
    • Python 3.9.13 环境
    • 基础通信组件

三、安装流程

  1. 双击 .exe 安装文件
  2. 阅读欢迎信息 → 下一步
  3. 勾选接受许可协议 → 下一步
  4. 选择产品（Mech-Vision + Mech-Viz）→ 勾选桌面快捷方式 → 下一步
  5. 设置安装路径 → 下一步
  6. 确认安装 → 安装
  7. 等待完成 → 完成

注意：

  • 系统盘需预留足够空间（安装包先在系统盘解压）
  • 首次打开软件需允许防火墙通过

四、升级软件

  • 运行新版本安装包 → 选择「升级，保留历史版本」或「升级，删除历史版本」
  • 注意：软件不支持直接从 1.6.0 之前版本升级

五、卸载/修复/修改

操作 方式
卸载 安装向导 → 维护 → 卸载 或 控制面板 → 程序和功能
修复 安装向导 → 维护 → 修复
修改 安装向导 → 维护 → 修改（添加/移除组件）

六、常见安装问题

  1. 安装包未能启动 → 系统盘空间不足，需清理
  2. 安装失败 → 校验完整性、以管理员运行、检查用户账户控制弹窗、重启后重试
